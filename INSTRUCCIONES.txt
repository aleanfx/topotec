# Instrucciones de Ejecución Local - Web Topotec

Para ejecutar este proyecto en tu computadora local, sigue cualquiera de estos métodos:

### Método 1: Apertura Directa (Más Rápido)
1. Busca el archivo `index.html` en la carpeta raíz del proyecto.
2. Haz clic derecho sobre él y selecciona **"Abrir con"** -> Tu navegador preferido (Chrome, Firefox, Edge, etc.).

### Método 2: Servidor Local con VS Code (Recomendado para Desarrollo)
1. Abre la carpeta del proyecto en **Visual Studio Code**.
2. Instala la extensión **"Live Server"** si no la tienes.
3. Haz clic en el botón **"Go Live"** en la barra inferior de VS Code.

### Método 3: Servidor Local por Consola (Si tienes Python o Node instalado)

**Con Python:**
1. Abre una terminal en la carpeta del proyecto.
2. Ejecuta: `python -m http.server 8000`
3. Abre tu navegador en: `http://localhost:8000`

**Con Node.js:**
1. Abre una terminal en la carpeta del proyecto.
2. Ejecuta: `npx serve`
3. Abre tu navegador en la dirección que indique la consola (normalmente `http://localhost:3000`).

---
**Nota:** El proyecto está compuesto por archivos estáticos (HTML, CSS, JS), por lo que no requiere de una base de datos ni de una instalación previa de dependencias para funcionar.
